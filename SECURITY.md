# Security Policy

## Supported Versions

安全修复只覆盖当前发行线。版本号以 `pyproject.toml` 为准；仓库没有更早的发行标签，默认分支与这一发行线是同一条。

Security fixes cover the current release line only. The version is the one in `pyproject.toml`. This repository has no older release tags, and the default branch is that same line.

支持的版本：

| Version | Supported |
| --- | --- |
| 0.1.x | yes |
| < 0.1.0 | no |

## Reporting a Vulnerability

没有公开的安全邮箱。请通过 GitHub Private vulnerability reporting 私下报告漏洞，不要把尚未修复的漏洞发到公开 issue。

There is no public security email. Report vulnerabilities privately through GitHub Private vulnerability reporting. Do not file an unfixed vulnerability as a public issue.

https://github.com/ax128/AegisGate/security/advisories/new

请写明受影响的版本和复现步骤，并说明是否希望被致谢。不要附带真实密钥。

Include the affected version and the steps to reproduce, and say whether you want to be credited. Do not include real secrets.

## Response window

响应时限：私下报告会在 7 天内得到确认。确认后，维护者会说明报告是否被接受，并在修复公开前与报告者协调披露时间。

We acknowledge a private report within 7 days. After that acknowledgement we will say whether the report is accepted, and we will coordinate disclosure with the reporter before a fix is published.
